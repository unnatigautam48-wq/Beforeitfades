# BeforeItFades design direction

The MVP uses a dark legal-operations workspace aesthetic: deep navy surfaces for focus and trust, warm amber for time-sensitive attention, teal for human-review safeguards, and restrained serif display type for editorial authority. The interface is intentionally a workflow dashboard rather than a chatbot. It uses a persistent case-oriented sidebar, a radar as the visual anchor, and source-linked detail panels to make the product story immediately legible.
